## Workspace tabs (required by the user)
Evidence: `EB27363B` (titlebar tabs: icon + truncated label, spinner icon on a loading tab, unread dot, `+` at far right; back/forward/history on the left; active tab = subtle filled pill), `DB2A4628` (one titlebar tab with avatar icon + `+`), `F046D5DF` (tab `feat(projects)…` + `+` above the PR view), `ADFBCD30` (panel tab strip `Tasks · Filesystem · Changes · Branch ✕ + ▾ ⤢ ▯`).
- **Visual**: 28–32px strip; tab = 16px icon + label (truncate ~180px) + ✕ shown on the active or hovered tab; the active tab uses a light fill, not an underline; the leading icon shows state (spinner = running, dot = unread or needs-you, purple = merged); `+` and an overflow `▾` come at the end.
- **Interaction**: tabs can point at a project, board, list, doc, run trace, review or tour; ⌘T new, ⌘W close, ⌘⇧[ ] cycle, middle-click close, drag to reorder; back/forward history is per tab; the toolbar popover's “promote to tab” (ADFBCD30) opens a popover's content as a tab.
- **Motion**: opening a tab expands its width from 0 to its natural width (~200ms ease-out) and the neighbours slide; closing collapses its width and the neighbours slide in; dragged tabs reorder with position springs. When content is promoted, keep the content in place and fade out only the popover chrome (~150ms). Switching tabs swaps the content with no slide (instant or a 100ms crossfade).
- Persist open tabs and the active tab per workspace in Bun SQLite (see Storage).

## Storage (user decision)
Use a real service-backed store: Bun `bun:sqlite` with CRUD endpoints for projects, tasks, docs, templates, workflow configs, and workspace tabs/layout. The user owns scheduling, integrations, the harness and the VM execution scaffold. Until those exist, the UI can display run, trace and stats data only as stored records or clearly labelled fixtures.

## Motion guidance (GPUI Kit Motion)
- Popover from trigger: scale/size from trigger origin, 250–300ms ease-out (no bounce); content-swap inside open popover: height animate ~200ms + 120ms crossfade.
- Hover popover on dense rails: open delay ~100ms, instant handoff between neighbours.
- Expand/collapse grouped items: 300–400ms ease-out on positions; never animate text reflow per frame.
- Live counters/status (badge counts, “Running for 1m”, seconds): text swap, optional 150ms number roll; spinner for active step.
- Respect reduced motion: replace movement with opacity.
- Camera zooms in the videos are presentation-only — do not build.

## Material conflicts
1. **Theme**: dark refs (`803531A8`, `DB2A4628`, `CCCF2D3A`) vs light refs (rest). Need both themes, or a decision on default.
2. **Review tabs** differ: `Summary/Guide/Timeline/Code` (803531A8) vs `Overview/Guide/Diff` (F046D5DF). Pick one set.
3. **Navigation**: the refs show an icon rail plus sidebar (AE10217A), a sidebar only (EB27363B, 669B3D47), titlebar workspace tabs (EB27363B, DB2A4628, F046D5DF) and panel-level tabs (ADFBCD30). Recommended: a sidebar for navigation, titlebar tabs for open work items, and a panel tab strip only inside the run inspector. These need confirming.
4. **Icons**: refs use thin monochrome outline icons (Lucide-like). Kubai icons are layered, multi-tone, gradient, with drop shadow — visually heavier. Using Kubai everywhere will not match the references' nav/toolbars. Suggest Kubai for larger/feature icons (empty states, template tiles, sidebar section glyphs, onboarding) and confirm with user for 16px chrome.
5. Provider brand logos in trace (Anthropic, OpenAI, GitHub, Notion, Figma, Stripe, HubSpot) are trademarks — not in Kubai; need official brand assets per each brand's guidelines.

## Kubai icons feasibility
- Site: https://icons.kubai.design (beta). 3,078 icons in `kubai-icons-static@0.15.0` `icons.json` (site claims 3,580 incl. two-tone). GitHub `kubai087/kubai-icons`.
- **License**: icons + packages MIT (`LICENSE-ICONS`); keep the copyright notice with source; attribution in shipped product not required. Website is all-rights-reserved (don't scrape site assets); skill is source-available. Kubai name/logo not licensed.
- **Usable path for GPUI (no JS)**: `kubai-icons-static` → `svg/<name>.svg` (blue #5393FF) and `svg-soft/` (blue-grey). CDN: `https://cdn.jsdelivr.net/npm/kubai-icons-static@0.15.0/svg/folder.svg` (verified 200). Pin exact version; vendor files into repo with LICENSE. Files include shadow margin: display at 28px to match 24px.
- Documented colour API `https://icons.kubai.design/api/icon/<name>.svg?color=HEX` returned **404** on 2026-11-24 — don't depend on it. Recolour by build-time hex substitution or browser download panel.
- **GPUI caveat**: `svg()` element renders as a single-colour mask tinted by text colour — it will flatten Kubai's gradients/tones. Use `img()` with the SVG (full-colour rasterisation) or pre-render PNG at 1x/2x. Hover motion lives only in the JS packages; GPUI would show the rest pose unless motion is reimplemented.
